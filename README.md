# GK Crédit

Application Android de gestion des ventes à crédit.

## Première version
- Connexion administrateur
- Gestion des clients
- Gestion des articles
- Suivi des crédits
- Suivi des paiements
- Historique
- Tableau de bord
- Rapport PDF
- Base de données SQLite locale

## Compte initial
- Utilisateur : `admin`
- Mot de passe : `admin123`

## Génération APK
GitHub Actions compile automatiquement une version Release avec JDK 17, Gradle 8.7 et Android Gradle Plugin 8.6.1.

Le fichier généré est : `app/build/outputs/apk/release/app-release.apk`.
